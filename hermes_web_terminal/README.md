# Hermes Web Terminal — ترمینال هرمس توی مرورگر (بدون پریدن سشن)

هدف این اسکریپت **رابط چت جدید نیست** — دقیقاً همون محیط ترمینالیِ خودِ هرمس
(`hermes -p conduit`) رو توی مرورگر باز می‌کنه، با یه تفاوت مهم:

> سشن هرمس داخل **tmux** روی سرور اجرا میشه. پس وقتی نتت قطع/وصل شد،
> سشن **نمی‌پره**؛ فقط صفحه رو رفرش می‌کنی و دقیقاً همونجا که بودی برمی‌گردی.
> دیگه لازم نیست از نو سشن استارت بزنی.

- ✅ همون TUI واقعی هرمس، نه یه چت‌باکسِ تقلیدی.
- ✅ مقاوم در برابر قطعیِ نت (سشن سمت سرور زنده می‌مونه).
- ✅ فارسی از طریق مرورگر (xterm.js / UTF-8) رندر میشه — تمیزتر از ترمینال خراب.
- ✅ ریسپانسیو موبایل، پورت قابل انتخاب، ورود اختیاری با یوزر/پس.

پشت صحنه: **tmux** (ماندگاری سشن) + **ttyd** (سرو کردن ترمینال روی وب).

---

## اجرا

```bash
cd hermes_web_terminal
./hermes-web-term.sh                          # پروفایل conduit، پورت 8787
```

بار اول اگه `tmux` یا `ttyd` نصب نباشن، خودش نصبشون می‌کنه
(اول با apt؛ اگه نشد، باینری استاتیک ttyd رو توی `~/.local/bin` دانلود می‌کنه — بدون نیاز به sudo).

بعد توی مرورگر:

```
http://<آی‌پی-سرور>:8787/
```

از گوشی هم توی همون شبکه با آی‌پی سرور باز میشه.

### وقتی نتت قطع شد
هیچ کاری نکن — فقط **صفحه رو رفرش کن**. سشن هرمس توی tmux زنده مونده و
دوباره به همونجا وصل میشی.

## گزینه‌ها

| فلگ | متغیر محیطی | پیش‌فرض | کار |
|---|---|---|---|
| `--port` | `PORT` | `8787` | پورت وب (چون پورتات مشغولن، راحت عوضش کن). |
| `--profile` | `PROFILE` | `conduit` | پروفایل هرمس (`hermes -p <name>`). |
| `--session` | `SESSION` | `hermes` | اسم سشن tmux. |
| `--iface` | `IFACE` | `0.0.0.0` | آدرس bind. برای فقط-لوکال: `127.0.0.1`. |
| `--cred` | `CRED` | — | ورود با پسورد: `user:pass`. |
| `--fontsize` | `FONTSIZE` | `16` | اندازه فونت. |
| `--font` | `FONTFAMILY` | Vazirmatn… | فونت (اگه فونت فارسی رو مرورگرت نصبه بذارش اول لیست). |
| `--cmd` | `HERMES_CMD` | `hermes -p <profile>` | کل دستور رو دستی تعیین کن. |

مثال‌ها:

```bash
./hermes-web-term.sh --port 9000 --profile conduit
./hermes-web-term.sh --cred ali:1234              # با صفحه‌ی ورود
PORT=9000 ./hermes-web-term.sh
./hermes-web-term.sh --cmd '~/.local/bin/hermes -p conduit'   # مسیر دلخواه هرمس
```

## مدیریت سشن با دست

```bash
tmux ls                       # لیست سشن‌ها
tmux attach -t hermes         # وصل شدن از خود ترمینال سرور
tmux kill-session -t hermes   # بستن کامل سشن (دفعه بعد از نو استارت می‌خوره)
```

> **عوض کردن پروفایل:** چون سشن زنده دوباره ساخته نمیشه، اول
> `tmux kill-session -t hermes` بزن، بعد اسکریپت رو با `--profile` جدید اجرا کن.

---

## دسترسی از موبایل و امنیت

- چون `IFACE=0.0.0.0` هست، از گوشیِ توی همون شبکه در دسترسه. فایروال؟
  ```bash
  sudo ufw allow 8787/tcp
  ```
- **اگه روی اینترنت بازه**، حتماً `--cred user:pass` بذار. برای امنیت بیشتر
  بهتره پشتش یه reverse proxy با HTTPS (مثل Caddy/Nginx) بذاری، چون
  basic-auth بدون TLS رمز رو رمزنگاری‌شده نمی‌فرسته.

---

## اجرای دائمی (systemd)

`hermes-web-term.service` رو طبق توضیحات داخلش ویرایش و نصب کن:

```bash
sudo cp hermes-web-term.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now hermes-web-term
journalctl -u hermes-web-term -f
```

## چرا فارسی اینجا بهتره؟

ترمینال‌های SSH خیلی وقتا shaping/bidi فارسی رو خراب نشون میدن. اینجا خروجی
توی **xterm.js** داخل مرورگر رندر میشه که UTF-8 رو درست می‌فهمه و فونت فارسی
مرورگر رو استفاده می‌کنه. اگه می‌خوای صددرصد یکدست باشه، فونت **Vazirmatn** رو
روی همون دستگاهی که مرورگر رو باز می‌کنی نصب کن (اسکریپت خودش اول لیست فونت‌ها
گذاشتتش).
