# Hermes Web Chat — چت وب فارسی برای Hermes

یه رابط چت وب **تمیز، ریسپانسیو و راست‌به‌چپِ درست** برای Hermes Agent.
هدف: به‌جای اینکه توی ترمینال فارسی بهم بریزه، توی مرورگر (موبایل یا دسکتاپ)
یه پروفایل انتخاب کنی و راحت چت کنی.

- ✅ فقط با **پایتون استاندارد** کار می‌کنه (هیچ چیزی نصب نمی‌کنی، نه pip نه npm).
- ✅ فارسیِ **درست** (RTL + `dir=auto`) — کد و متن انگلیسی هم چپ‌به‌راست و مرتب.
- ✅ **استریم زنده** (کلمه‌به‌کلمه، مثل ترمینال).
- ✅ انتخاب **پروفایل** (مثل `hermes -p conduit`) و **مدل** از منو.
- ✅ **ریسپانسیو موبایل**، تم تاریک/روشن خودکار، ذخیره‌ی گفتگو در مرورگر.
- ✅ پورت **کاملاً قابل انتخاب**.

---

## پیش‌نیاز: endpoint سازگار با OpenAI

این اپ به یه سرور **OpenAI-compatible** وصل میشه. توی Hermes با این دستور بالا میاد:

```bash
hermes proxy            # پیش‌فرض روی پورت 8645 بالا میاد
# یا برای یک پروفایل خاص:
hermes -p conduit proxy
```

یعنی endpoint‌ت میشه چیزی مثل `http://127.0.0.1:8645/v1`.
(اگه پورت proxy رو عوض کردی، توی `config.json` هم همون رو بذار.)

## اجرا

```bash
cd hermes_web
python3 server.py
```

بار اول اگه `config.json` نباشه، خودش یه نمونه می‌سازه. بازش کن و تنظیمش کن
(نمونه‌ی کامل: `config.example.json`). بعد باز اجرا کن.

بعد توی مرورگر باز کن:

```
http://<آی‌پی-سرور>:8787/
```

### انتخاب پورت
سه راه (هر کدوم رو خواستی):

```bash
python3 server.py --port 9000      # آرگومان خط فرمان
PORT=9000 python3 server.py        # متغیر محیطی
# یا فیلد "port" توی config.json
```

اگه فقط روی خود سرور می‌خوای، می‌تونی `--host 127.0.0.1` بدی تا از بیرون در دسترس نباشه.

## تنظیمات `config.json`

```json
{
  "host": "0.0.0.0",
  "port": 8787,
  "access_token": "",
  "default_profile": "conduit",
  "profiles": {
    "conduit": {
      "label": "Conduit",
      "base_url": "http://127.0.0.1:8645/v1",
      "api_key": "",
      "model": "hermes",
      "temperature": 0.7,
      "system_prompt": "",
      "soul_file": "~/.hermes/profiles/conduit/SOUL.md"
    }
  }
}
```

| فیلد | توضیح |
|---|---|
| `base_url` | آدرس سرور OpenAI-compatible (با `/v1`). |
| `api_key` | اگه سرورت کلید می‌خواد بذار، وگرنه خالی. |
| `model` | اسم مدل. توی UI هم قابل تغییره (از `/v1/models` پر میشه). |
| `system_prompt` | پرامپت سیستمی مستقیم (اختیاری). |
| `soul_file` | مسیر یه فایل مثل `SOUL.md` که به‌عنوان system prompt خونده میشه. |
| `access_token` | اگه پرش کنی، صفحه باید با `?token=...` باز بشه (برای امنیت روی شبکه). |

### چند پروفایل
هر کلید زیر `profiles` یه پروفایله و توی دراپ‌داونِ بالای صفحه ظاهر میشه —
دقیقاً مثل انتخاب `hermes -p <name>`. می‌تونی هر پروفایل رو به `SOUL.md`
مربوط به همون پروفایل توی `~/.hermes/profiles/<name>/` وصل کنی.

## دسترسی از موبایل

چون `host` روی `0.0.0.0` هست، از گوشی توی همون شبکه با
`http://<آی‌پی-سرور>:8787/` باز میشه. اگه فایروال داری، پورت رو باز کن:

```bash
sudo ufw allow 8787/tcp
```

**نکته امنیتی:** اگه سرورت روی اینترنت باز است، حتماً `access_token` بذار
(یه رشته‌ی تصادفی) و صفحه رو با `?token=همون‌رشته` باز کن.

---

## اجرای دائمی (systemd)

فایل `hermes-web.service` رو طبق توضیحات داخلش ویرایش و نصب کن:

```bash
sudo cp hermes-web.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now hermes-web
journalctl -u hermes-web -f
```

## میان‌برها

- `Enter` = ارسال، `Shift+Enter` = خط جدید.
- دکمه‌ی «＋ جدید» = گفتگوی تازه (گفتگوی هر پروفایل جدا در مرورگر ذخیره میشه).
- وسط استریم، دکمه‌ی «ارسال» تبدیل به «توقف» میشه.
